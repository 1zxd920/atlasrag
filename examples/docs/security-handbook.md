# Access Control

Every knowledge document has a department label and a visibility level.
Search results must be filtered before excerpts are shown to the answer layer.
Administrators review access grants every quarter.

# Audit Logs

Query, retrieval, and tool-call audit logs are retained for 180 days. Logs must
include the actor, trace identifier, selected sources, decision, and timestamp.
Security incidents are escalated to the on-call owner within 15 minutes.

# Data Handling

Secrets, passwords, and private keys must never be indexed. Personal data must
be minimized before ingestion and deleted when its retention period expires.
